# Foresight Scenario Engine

현실의 구조적 괴리에서 복수의 미래 세계를 발견하고, 그 안에서 살아가는 평범한 인간의 이야기를 쓰기 위한 창작 연구 저장소.

미래를 맞히거나 특정 정치적 결론을 입증하기 위한 프로젝트가 아니다. 세계관은 깊게, 이야기는 자연스럽게. 세계관이 아니라 이야기 자체의 매력이 최종 선택을 이끈다.

## 시작하기

- [AGENTS.md](AGENTS.md): 사람과 에이전트의 작업 진입점
- [core/CHARTER.md](core/CHARTER.md): 저자의 핵심 의도와 보호할 뿌리
- [core/DESIGN.md](core/DESIGN.md): 공통 골격과 격리 원칙
- [methodology/RESEARCH.md](methodology/RESEARCH.md): 조사 방법론 v0.2
- [methodology/SIMULATION.md](methodology/SIMULATION.md): 정치적 분기와 전환도 모형
- [research/README.md](research/README.md): 세계에 종속되지 않는 현실 조사
- [worlds/README.md](worlds/README.md): 독립적인 미래 세계
- [stories/README.md](stories/README.md): 독립적인 이야기 실험
- [lab/README.md](lab/README.md): 자유로운 실험
- [context/HANDOFF.md](context/HANDOFF.md): 현재 상태 및 다음 작업

## 구조

```
core/          # 뿌리와 공통 설계
methodology/   # 개선 가능한 연구 도구
research/      # 현실 관측과 가설, 공유 증거
worlds/        # 세계별 역사·제도·생활·정설
stories/       # 이야기별 초안과 상상
lab/           # 비정설 실험
context/       # 세션 인수인계 및 결정 기록
```

현재 단계: 초기 골격 v0.2. 실제 조사, 미래 세계의 확정, 소설 집필은 아직 시작하지 않았다. 이 저장소는 공개 상태이므로 개인 자료와 공개를 원하지 않는 창작 초안은 별도로 보관한다.
