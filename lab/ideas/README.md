# 독립 발상

조사 또는 일상에서 직관적으로 발견한 가능성을 보존한다. 현실 연구나 확정 세계의 일부가 아니다. 서로 모순되거나 미완성인 발상도 허용한다.

기록은 날짜, 간단한 발상 기전, 저자가 공개 보존을 승인한 원문, 당시 AI의 반응을 기본으로 한다. 원문 표현을 다듬지 않으며 최초 반응은 Markdown으로 옮긴다(시각 UI는 의미가 같은 텍스트로 변환). 이후 발상은 날짜를 붙여 추가할 수 있다. 점수·우선순위·검증 절차는 강제하지 않는다. 발상 기전은 필요하면 AI의 요약임을 명시한다. 공개 저장소라는 점에 유의한다.

연구·세계·이야기에 사용할 때는 해당 목적지에서 명시적으로 채택한다. 이곳의 아이디어를 읽거나 저장했다는 사실만으로 기존 연구나 다른 세계가 변경되지 않는다.
