# 독립 미래 세계

아직 정식 세계 없음. 정치적 분기 원형 A~E는 [모형 설명](../methodology/SIMULATION.md)에만 존재한다. 조사 후 1~5개의 주요 세계를 만들 수 있다. 숫자는 주요 정치적 경로를 뜻하며 하위 실험의 수를 제한하지 않는다.

세계별 독립 디렉터리(예: worlds/world-001/)를 사용한다. 최소한 README 하나로 시작하고 필요할 때 timeline.md, canon.md, institutions/, economy/, everyday/, experiments/ 등을 추가한다. [선택적 시작 양식](../methodology/WORLD-TEMPLATE.md).

공통 조사 참조와 채택된 가정, 분기점, 현재 상태(탐색/정설/보류 등)를 구별한다. 세계 내부의 가정과 실험은 다른 세계에 적용되지 않는다. 세계 간 아이디어 공유는 명시적으로 채택한다. 모든 세계를 서로 비교할 필요는 없다. 정설을 바꾸거나 독립 분기를 생성하는 선택은 해당 세계의 작업 범위에서 한다.
