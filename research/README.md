# 공유 현실 연구

세계관에 종속되지 않는 현실 관측과 검증 가능한 추론을 보관한다. 현재 실제 기록은 없다.

필요할 때 signals/, gaps/, themes/, human/, politics/, variables/ 등의 하위 폴더를 만든다. 대화나 작업 흐름에 더 적합하면 다른 분류도 허용한다.

| 유형 | 선택적 ID | 내용 |
|---|---|---|
| 관측 | SIG-001 | 날짜, 지역, 출처 URL, 실제 현상과 지표 |
| 괴리 | GAP-001 | 기존 약속·제도, 변한 조건, 충돌, 관련 관측 |
| 거대담론 | THEME-001 | 반복되는 구조와 반례 |
| 인간의 정서 | HUM-001 | 발화·행동·경험, 대표성 한계 |
| 정치 분기 | POL-001 | 이해관계, 선택지, 경로, 전파, 반작용 |
| 변수 | VAR-001 | 기준·목표·분모·범위·불확실성 |

간단한 기록에는 제목, 관측일/출처, 근거와 해석의 분리, 불확실성만으로 충분하다. ID나 파일 양식은 연결과 검색에 도움이 될 때만 사용한다. 한 기록에서 사실·해석·조건부 추론을 구분하고 세계관별 창작은 worlds/에 둔다. 출처는 실제 접근·확인한 것만 적는다. 전문 무단 복제 및 개인정보 기록은 피한다.
