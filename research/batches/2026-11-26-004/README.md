# Batch 004 — 희망의 대상, 이동하는 기회, 사회적 성취
기준일 2026-11-26. 15개 관측 기록(거시 6, 미시 5, 역사·비교 4), 괴리 후보 6개. 누계 62개 관측, 24개 후보 기록(중복·공유 출처 포함, 고유 담론 수 아님).

사회적 약속의 역사, 교육·주거 기회, 금융 접근, 복지 집행, 소비자 선택, 실제 보건 성취를 조사했다. 공개 웹 본문·초록·검색 결과에 근거한 탐색이다. 연구의 원자료 및 첨부 PDF 전체를 검토하지 않았으며 기사와 기관의 설명을 독립적으로 재현한 분석은 아니다. 거시·미시 기록은 구분하지만 독립 조사자나 블라인드 조사가 아니다. 학자의 정책 제안을 실현된 효과와 구분한다. 실제 성취와 반례를 포함하고, 희망의 상품화나 부조리의 이동을 보편 법칙으로 전제하지 않는다. 세계관·정치적 분기 미확정.
