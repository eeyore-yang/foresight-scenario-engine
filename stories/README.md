# 이야기 작업 공간

아직 작품 없음. 이야기는 세계관 구축과 별개로 발전할 수 있다.

작품별 디렉터리(예: stories/story-001/)에서 README, 초안, 인물, 장면 등을 필요에 따라 작성한다. 관련 세계가 있으면 세계 ID와 버전(커밋 또는 정설 버전)을 기록한다. 세계를 정하기 전에도 자유롭게 이야기를 구상할 수 있다.

이야기의 가정이나 서술자의 인식은 세계의 정설과 같지 않다. 작품별 예외나 대안은 해당 작품에서만 유효하다. 나중에 세계를 선택·변경하거나 작품별 세계를 분기할 수 있다. 이야기의 구조와 몰입이 우선이며, 세계 설정 설명을 위해 이야기를 희생하지 않는다.

공개 저장소에 공개를 원치 않는 초안을 넣지 않는다.
