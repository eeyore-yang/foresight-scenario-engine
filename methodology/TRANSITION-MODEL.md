# 전환도와 변수 사용 규칙 v0.1
[기존 시뮬레이션](SIMULATION.md)의 보조 사양. 헌장 변경 없음. 공통 연구의 변수 사전은 [research/variables](../research/variables/README.md). 실증 예측 모델이 아닌 창작을 위한 조건 탐색기다.

## 상태와 진행률
실제 관측 O, 가상 상태 S, 질적 판단 Q를 분리한다. 단일 수치가 적합한 S에는 출발 b, 목표 e, 가상 상태 v를 정의하고 전환도 x=100*(v-b)/(e-b)로 계산한다. e=b이면 정의되지 않는다. 0은 출발, 100은 명시한 목표로 도달. 100은 최선이 아니다. e<b인 감소 방향도 같은 식으로 표현. 0 미만은 역행, 100 초과는 목표 초과로 원값 보존(기존 0~100 표시 범위는 UI 편의에 한해 적용 가능). 목표를 바꾸면 같은 v의 x가 달라진다는 점에 주의한다. 비교하는 세계는 동일 기준/목표/정의/범위를 사용한다. 기준이나 목표가 미정이면 x도 미정. 시간당 변화가 일정하다고 가정하지 않는다.

## 괴리
1. 동일한 기준·분모의 직접 차이: 예를 들어 자격을 갖춘 동일 집단의 법적 보장률과 실제 수급률. 법적 보장과 수급이 중첩되지 않을 가능성까지 교차표로 점검한다.
2. 같은 전환 목적에 대해 합의된 정규화 척도가 있을 때만 진행도의 부호 있는 차이. 갈등 크기나 인과율이 아니다.
3. 상이한 단위(예: 여가분과 신뢰도, AI 사용률과 실업률)는 차이 계산 금지. 조건부 연결/서술로 남긴다.
4. 질적 관계(사랑·희망·애착·정치적 정당화)는 수치 대용품으로 만들지 않는다. 행동·발화·경험의 관찰과 문학적 가설로 기록.
25%p는 이전 개념모형의 임시 탐색 기준으로만 남기며 공통 임계값으로 사용하지 않는다. 실제 임계점은 해당 제도의 법적 요건, 공급 한계, 비용/시간 예산 등으로 정의한다.

## 시간·불확실성
상태마다 외생 충격, 방향, 느림/빠름의 조건, 지연, 범위, 근거 종류(관측/모형/가정), 가정이 틀릴 조건을 기록한다. 범위는 신뢰구간이 아닌 가상 탐색 범위라면 그렇게 표기한다. 역전·정체·재설계·분산 허용. 기술은 월~년, 제도는 변경과 실제 집행이 다르며 기반시설과 인구는 장기간이라는 시간 단위는 예시이지 확정 속도 아니다.

## 일관성 체크
- 하루 시간 예산 24시간(동시활동 중복 처리), 필요한 노동시간·고용·산출량·수요 구분.
- 이전소득/배당의 재원과 구매 가능한 실제 재화·서비스, 세금·부채·가격·소유권 연결.
- 에너지·물·자원 공급/전달/유지 및 국제 의존의 병목.
- 인구는 출생·사망·순이동, 코호트 및 가구 구성의 회계적 일관성.
- 법적 권한/집행/거부/구제는 별도. 제도나 AI가 인과적으로 영향을 주지 않는 영역도 남긴다.
- 생애의 비가역성, 인간의 모순·자발성, 사회적 성공의 긍정적 가능성을 유지.
정치 0.4 및 1~5개 주요 경로 유지. 숫자로 세계의 매력을 합산하지 않는다. [실험](../lab/transition-model/README.md)은 검증용 사고실험이며 정설이 아니다.
