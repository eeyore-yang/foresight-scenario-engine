# 세계 시작 양식 (선택)

- 세계 ID / 이름 / 상태
- 공통 현실의 기준 시점과 참조 버전
- 이 세계가 시작된 정치적 선택 및 다른 가능성
- 국제적 환경과 한국의 대응
- 권력이 퍼진 경로, 저항과 되먹임, 역사적 사건
- 변수와 전환도(기준·목표·근거·불확실성)
- 제도와 그 제도가 보호하는 약속
- 새로운 시장, 계층, 생활, 문화 및 관습
- 혜택을 얻는 사람과 잃는 사람
- 인간의 욕망과 원념, 해방과 기쁨
- 평범한 사람의 하루 또는 작은 사건
- 채택된 설정 / 실험 중인 설정 / 아직 모르는 것

필요한 항목만 쓰면 된다. 세계 내부의 정설은 해당 세계에 한정된다. 모순을 일부러 만드는 실험도 가능하다.
